# Progress review — 2026-09-07

Knox has substantial implemented systems, but is not yet a finished survivor
replacement. The largest remaining gap is integrated gameplay evidence and
recovery between systems, rather than the number of menu options. A percentage
complete would obscure the difference between implemented code and proven play.

## Current position

## Work next, in order

1. **One companion's complete day.** Recruit, collect food, eat/drink/treat,
   travel indoors/outdoors, fight/flee, board/exit, return home and save/reload.
   Record native effects and meaningful failures, then fix the first broken
   handoff. This is the highest-value next step after the reported hunger bug.
2. **One functioning settlement.** Designate the cupboard and Corpse Drop area.
   Use a hauler and other residents; observe actual corpse movement, surplus
   deposits, personal reserves and withdrawals for work. Test full/unreachable
   storage and three days of shortages. Test an old save migration separately.
3. **Small-group reliability.** One, four and twelve followers through chokepoints,
   separation and combat. Measure path retries, formation recovery and frame time.
4. **Driving implementation.** A disabled-by-default experiment with native driver
   ownership, steering, stopping and cancellation. Add obstacle handling and
   passengers only after that works. This is a real missing feature, not QA.
5. **World and release acceptance.** Extended offscreen/reload/event testing,
   compatibility, performance budgets, UI scaling and matched launcher/Workshop
   packaging. Validate updater integrity and rollback before release.

## Storage transition

Existing dry depot assignments migrate to one shared cupboard; otherwise the
player should designate an existing dry container through the base context menu.
Former storage contents stay where they were and can be moved manually. Native
containers retain ordinary food spoilage rules; the cupboard is not magical
refrigeration. There is no new furniture model or Rust-style authorization/upkeep.
Food/water reserves are item/container counts, not guaranteed days of nutrition.
Corpse haulers need a Corpse Drop work area. Supply deposits are personal upkeep,
not a separate hauling profession.

## Completion standard

Full completion requires all promised systems to have production implementations,
the companion/settlement/world loops to work together, durable state to survive
reconstruction, and remaining work to be primarily balance, optimization and
polish. Current work does not establish that standard. The most recent changes
are offline verified and still need the live cases above; no fresh gameplay
session was run for this review.
