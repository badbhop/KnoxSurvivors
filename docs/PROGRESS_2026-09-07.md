# Progress review — 2026-09-07

## Follow-up milestone

The central cupboard transition is now enforced at the storage boundary. A base
exposes one selected dry cupboard for deposits, withdrawals and summaries; former
category policies remain only long enough to migrate their reference and are not
used as alternate stores. Existing physical items are not moved or deleted.
Legacy sorting tasks and transfer targets are retired safely. Hauling orders and
automatic work use corpse handling, while resident cleanup deposits surplus at
home and preserves personal food, water, medical, ammunition, tool and job
reserves. Companion formation preferences survive base assignment and recall.

The flee controller now has a bounded last-resort panic route for passive or
otherwise noncombat survivors. When no checked escape lane exists and the
nearest threat cannot be handed to combat, it selects a short sprint target
that increases threat distance and avoids occupied tiles. Normal lane checks
and the adjacent-combat handoff remain authoritative.

The verified run is 86 Lua syntax checks, 94 Lua regression scripts and Java
check/build, 181 checks total. The next evidence still must come from a real game:
one companion day, one three-day base, group chokepoints/combat, and streaming /
save reload. No percentage-complete claim is made from this offline result.

Knox has substantial implemented systems, but is not yet a finished survivor
replacement. The largest remaining gap is integrated gameplay evidence and
recovery between systems, rather than the number of menu options. A percentage
complete would obscure the difference between implemented code and proven play.

## Storage transition

Existing dry depot assignments migrate to one shared cupboard; otherwise the
player should designate an existing dry container through the base context menu.
The persistence boundary now rejects new category-specific storage policies and
keeps exactly one central cupboard reference per base. Legacy records are read
and collapsed only during migration; their physical contents are not moved or
deleted.
Former storage contents stay where they were and can be moved manually. Native
containers retain ordinary food spoilage rules; the cupboard is not magical
refrigeration. There is no new furniture model or Rust-style authorization/upkeep.
Food/water reserves are item/container counts, not guaranteed days of nutrition.
Corpse haulers need a Corpse Drop work area. Supply deposits are personal upkeep,
not a separate hauling profession.

## Completion standard

Full completion requires all promised systems to have production implementations,
the companion/settlement/world loops to work together, durable state to survive
reconstruction, and remaining work to be primarily balance, optimization and
polish. Current work does not establish that standard. The most recent changes
are offline verified and still need the live cases above; no fresh gameplay
session was run for this review.
