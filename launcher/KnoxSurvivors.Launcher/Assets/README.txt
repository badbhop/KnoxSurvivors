Place your launcher artwork here as:

  background.png  (preferred, lossless)
  or background.jpg

Use the full-quality export (16:9, 1920x1080 or 2560x1440 ideal).
The launcher draws it with cover-fit + HighQualityBicubic so it stays
sharp and never stretched. Anything missing falls back to the solid
dark background, so the launcher still runs without the file.

The file is copied next to KnoxSurvivorsLauncher.exe on build
(see KnoxSurvivors.Launcher.csproj Content CopyToOutputDirectory).
