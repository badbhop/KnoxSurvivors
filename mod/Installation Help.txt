KNOX SURVIVORS 0.3.0-rc1 - INSTALL AND PLAY

WHAT TO SUBSCRIBE TO
Subscribe to both Knox Survivors and its required dependency, KnoxBridge Runtime.
The Knox Survivors Workshop page should list KnoxBridge Runtime under Required
Items. Steam will download the dependency automatically when that link is set.

ONE-TIME RUNTIME SETUP
The Bridge Workshop item is only a dependency marker; it does not contain the
installer. Download the setup package from:
https://github.com/exe-create/KnoxBridge/releases/latest

Windows:
1. Download and run KnoxBridgeSetup.exe.
2. Choose **1** to install/update and follow the prompts. It uses PZ's bundled
   Java; do not add custom Steam Launch Options or install another Java runtime.

Linux/macOS:
1. Download and extract the KnoxBridgeRuntime ZIP.
2. Close Steam, then run `sh scripts/setup-unix.sh` from the extracted folder.
   Python 3 is required. This setup path is implemented but not live-verified.

Then enable Knox Survivors in the PZ Mods menu and start Project Zomboid
normally through Steam. Use a new disposable save while this candidate is tested.

FIRST-RUN MODULE APPROVAL
The first launch records Knox's exact Java module hash and blocks it pending
approval. Exit the game, run the downloaded KnoxBridge setup again, choose
module trust management, check the module ID and SHA-256, then type **ALLOW** or
**DENY** for that exact JAR. Restart through Steam. A changed JAR has a new hash
and needs a new decision. You can also disable the mod itself in the normal PZ
Mods menu.

CHECK
After reaching the main menu, open Documents\Zomboid\KnoxIsoPlayer.log and
Documents\Zomboid\KnoxBridge\knoxbridge.log. Look for Knox module load PASS and
KnoxJavaBridge exposure. If the Knox module is missing, check that the runtime
was installed, the dependency is enabled, and the displayed hash was approved.

Use a disposable save and back up saves you care about. The installer changes
game startup configuration, not save files; Knox save compatibility is not
certified for important existing saves. Single-player is the focus; bugs are
expected. Do not run KnoxBridge at the same time as another Java instrumentation
bootstrap.

KnoxBridge loads only enabled PZ mods that declare its module descriptor and
implement the KnoxBridge API. Existing Java mods for other loaders do not load
automatically; their authors must port/support KnoxBridge. Java modules run with
the game's full permissions and are not sandboxed.

If KnoxBridge Runtime remains private, only accounts allowed to access that
Workshop item can use Knox Survivors; make the dependency public before a public
Knox release.
