KNOX SURVIVORS 0.3.0-rc1 - STARTUP SETUP

The current human NPC rebuild needs the Knox Java runtime loaded when Project Zomboid starts.
Use ONE method only.

WINDOWS / STEAM-ONLY
1. Steam > Project Zomboid > Properties > General > Launch Options
2. Paste the line below that matches your Steam location.
   C: drive Steam (most people):

-javaagent:"C:\Program Files (x86)\Steam\steamapps\workshop\content\108600\3749727604\mods\KnoxSurvivors\java\knox-agent.jar"=pz-game --

   D: drive library:

-javaagent:"D:\SteamLibrary\steamapps\workshop\content\108600\3749727604\mods\KnoxSurvivors\java\knox-agent.jar"=pz-game --

   Steam somewhere else? Keep the line identical and swap only the front part
   for your Steam folder. (Steam > Project Zomboid > Manage > Browse local
   files shows your folders.)
3. Start the game through Steam, enable Knox Survivors, and play.
This passes the Knox Java agent directly to Project Zomboid through Steam. No terminal window is required.

If Windows shows Entry Point Not Found naming another Java installation's java.dll
(you have a separate Java/JDK installed), paste this longer line instead. It gives
the game's own Java priority for that launch only, without changing global settings.
Change both folders if Steam is installed elsewhere:

cmd /d /v:off /s /c "set "PATH=C:\Program Files (x86)\Steam\steamapps\common\ProjectZomboid\jre64\bin;C:\Program Files (x86)\Steam\steamapps\common\ProjectZomboid\jre64\bin\server;%PATH%" && %command% -javaagent:"C:\Program Files (x86)\Steam\steamapps\workshop\content\108600\3749727604\mods\KnoxSurvivors\java\knox-agent.jar"=pz-game --"

A command window may appear in this mode. Keep your original options for rollback.

If you used Custom Launch Options inside the optional Knox launcher, copy those game arguments
after the final -- in Steam. Launcher-only preferences cannot migrate into Steam automatically.
