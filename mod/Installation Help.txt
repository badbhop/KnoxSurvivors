KNOX SURVIVORS 0.3.0-rc1 - INSTALLATION HELP

Knox Survivors supports TWO Java runtime options. ZombieBuddy is recommended, but it is not required.

OPTION A - ZOMBIEBUDDY (RECOMMENDED)
1. Install/configure ZombieBuddy using its official instructions.
   Steam Workshop item: 3619862853
2. Enable Knox Survivors. Enable ZombieBuddy when using this path.
3. Remove OLD Knox-only startup options such as:
   - -javaagent:...knox-agent.jar=pz-game
   - knox-steam-launch.cmd
4. Launch Project Zomboid normally through the ZombieBuddy-configured launch.
5. If ZombieBuddy asks to load Knox's Java JAR, approve it only if you trust the build.

Expected log:
  runtime start PASS source=zombie-buddy-patch-api

OPTION B - KNOX LAUNCHER (NO ZOMBIEBUDDY)
1. Enable Knox Survivors.
2. Do not use ZombieBuddy for this launch.
3. Start Project Zomboid using the Knox Launcher / existing Knox legacy Java-agent setup.

Expected log:
  runtime start PASS source=legacy-javaagent

CHECK
Open Documents\Zomboid\KnoxIsoPlayer.log after reaching the menu.
If no runtime PASS line appears, Knox's Java runtime did not start.

Target game: Project Zomboid 42.20.4
