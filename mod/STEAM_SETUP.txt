KNOX SURVIVORS 0.3.0-rc1 - JAVA RUNTIME SETUP

ZombieBuddy is OPTIONAL. Choose ONE startup method per launch.

METHOD A - ZOMBIEBUDDY (RECOMMENDED)
- Install/configure ZombieBuddy.
- Enable Knox Survivors and ZombieBuddy.
- Remove Knox's old -javaagent line / knox-steam-launch.cmd for this method.
- Launch normally through the ZombieBuddy-configured game launch.
- Approve the Knox Java JAR if ZombieBuddy prompts you and you trust this build.

Expected KnoxIsoPlayer.log line:
  runtime start PASS source=zombie-buddy

METHOD B - KNOX LAUNCHER (NO ZOMBIEBUDDY)
- Enable Knox Survivors.
- Do not use ZombieBuddy for this launch.
- Launch through the Knox Launcher / existing Knox legacy Java-agent setup.

Expected KnoxIsoPlayer.log line:
  runtime start PASS source=legacy-javaagent

Do not intentionally combine both startup methods.

Target game: Project Zomboid 42.20.4
Single-player focus. Use a fresh save for release-candidate testing and back up saves you care about.
